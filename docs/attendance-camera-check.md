# 출석 카메라 실기기 확인

자동 테스트는 카메라 설정과 예외 처리를 검증합니다. 실제 화질·초점·줌 동작은 아직 실기기 확인이 필요합니다.

## 확인 환경

- 문제가 발생한 갤럭시에서 Chrome과 Samsung Internet으로 각각 확인합니다.
- 카메라를 사용할 수 있는 HTTPS 주소로 접속합니다.
- 변경 전후에 같은 QR 코드, 거리, 조명을 사용합니다.

## 확인 순서

1. QR 출석 인증 화면에서 카메라를 시작하고 **카메라 정보**를 펼칩니다.
2. 실제 해상도·줌 배율·초점 모드를 기록합니다. 1080p는 우선 요청값이며, 미지원 기기는 더 낮은 해상도로 동작할 수 있습니다.
3. 기본 배율에서 QR의 작은 글자와 경계가 선명한지 확인합니다. 거리를 바꿨을 때 초점이 다시 잡히는지도 확인합니다.
4. 카메라 아래의 줌 슬라이더를 드래그하며 실제 줌 배율과 해상도를 확인합니다. 빠르게 드래그한 뒤 마지막으로 선택한 배율이 적용되는지도 확인합니다. 줌 미지원 시 안내가 표시되고 스캔이 계속되어야 합니다. 배율만으로 광학 줌 여부를 판단할 수는 없습니다.
5. 취소하고 다시 시작해 영상이 정상적으로 나오는지 확인합니다. 시작 직후 취소하거나 화면을 나갔을 때 카메라가 계속 켜져 있지 않아야 합니다.
6. 유효한 출석 QR을 스캔해 한 번만 출석 처리되는지 확인합니다. 실제 출석 기록이 생성되므로 테스트용 행사 또는 출석할 행사에서 수행합니다.
